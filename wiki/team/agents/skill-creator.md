# Skill Creator

> **Função:** Atalho lightweight pra criar skill nova no Claude Code rapidamente. Use quando precisar gerar SKILL.md básico em menos de 10 minutos, prototipar skill antes de auditoria completa, criar skill simples 
> **Categoria:** Scrapers e Ferramentas

## Como invocar

Você fala sempre com o CEO. Ele invoca este agente via:
```
Agent(subagent_type: "skill-creator", prompt: "<sua tarefa>")
```

## Definição completa do subagent

Ver `.claude/agents/skill-creator.md`.
